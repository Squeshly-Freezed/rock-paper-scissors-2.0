# rock-paper-scissors-2.0
Fun and easy Rock Paper Scissors! Version 2.0


Version 2.0 was salvaged from the corrupted repository of version 1.0.


In this project I've the main concepts I've learnt more about and practised:


Flexbox, having elements positioned along the z-axis (z-index), basic transition animations,
handling events and listeners; including utilising the 'event' object, creating a more responsive design by using vw and vh units instead of px units, more detailed font styling, using the dialog element for pop-up boxes, practiced writing more functions, and using classLists for elements.


Things to improve: Get the scoreboard working, stop the slight drop of the rock-paper-scissors icons when clicked, stop the raise of chosen icons when win or lose pop-up box appears.
